# Stumpy-z-test

Mobile test build of two screens from the Figma file **Mobile-test-1**:

- `index.html`: Mobile 01, Entry (Z Home)
- `journey-hub.html`: Mobile 02, Journey Hub

Plain HTML/CSS/JS, mobile-first (designed at 390 px wide, max 430 px; it stays a centred phone column on desktop).

The Figma mock-up's fake phone chrome (status bar, URL bar, browser toolbar) is left out because the real phone supplies its own.

Taps that lead to screens not built yet show a short message instead of doing nothing.
